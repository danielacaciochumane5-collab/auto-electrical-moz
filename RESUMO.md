## 🚀 COMO USAR AGORA

### Opção 1: Testar Localmente (FÁCIL)

```bash
# 1. Abra o site (sem backend)
python -m http.server 8000
# Depois: http://localhost:8000

# 2. Em outra aba, inicie o backend
cd backend
python app.py
# Depois: http://localhost:5000/api/health
```

### Opção 2: Publicar Online (RECOMENDADO)

Siga o arquivo **DEPLOY.md** - 3 opções:

1. **Heroku** (Mais fácil) - ~5 minutos
2. **GitHub Pages** (Frontend) - ~2 minutos  
3. **PythonAnywhere** (Backend) - ~10 minutos
